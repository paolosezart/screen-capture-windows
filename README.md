# ScreenShotCli

Небольшая консольная утилита для Windows: захватывает прямоугольную область виртуального рабочего стола и сохраняет её в PNG.

Текущая реализация — **Go 1.23**, Windows x64, без внешних библиотек и без установленного .NET Runtime.

## Скачать

Основное место загрузки — [GitHub Releases](https://github.com/paolosezart/screen-capture-windows/releases):

- **Latest continuous build** — последняя успешная сборка из ветки `main`; предварительный релиз, обновляется автоматически.
- **Release vX.Y.Z** — стабильная версия, создаваемая отправкой тега вида `v1.0.0`.

Каждый релиз содержит:

- `ScreenShotCli-win-x64.zip` — ZIP с автономным EXE.
- `SHA256SUMS.txt` — контрольная сумма ZIP.

Actions Artifacts сохраняются дополнительно для проверки CI, но для обычного скачивания использовать их не нужно.

## Использование

```bat
ScreenShotCli.exe --x 0 --y 0 --width 800 --height 600 --output "C:\Screenshots\part.png"
ScreenShotCli.exe --x 100 --y 200 --width 1280 --height 720 -o "D:\Capture\screen.png"
ScreenShotCli.exe --help
```

Параметры:

- `--x`, `--y` — координаты левого верхнего угла области.
- `--width`, `--height` — ширина и высота в пикселях.
- `--output` или `-o` — путь к выходному PNG-файлу.

Координаты отсчитываются от левого верхнего угла виртуального рабочего стола Windows. Мониторы, расположенные слева или выше основного, могут иметь отрицательные координаты.

## Поведение и ограничения

- Папка назначения создаётся автоматически.
- Существующий файл перезаписывается.
- Вся область должна находиться внутри виртуального рабочего стола.
- Максимальная сторона — 16384 пикселя; максимальная площадь — 100 000 000 пикселей.
- Захватывается интерактивный рабочий стол текущего пользователя. Курсор отдельно не рисуется.
- Защищённые экраны и DRM-видео могут не захватываться.
- Не запускай программу от администратора без необходимости.

## Сборка из исходников

Требуется Go 1.23 или новее:

```powershell
$env:GOOS = "windows"
$env:GOARCH = "amd64"
$env:CGO_ENABLED = "0"
go build -trimpath -ldflags="-s -w" -o ScreenShotCli.exe .
```

Используются только стандартная библиотека Go и Win32 API (GDI/User32). Cgo и сторонние Go-модули не требуются.

## CI/CD

Workflow собирает Windows x64 EXE на GitHub Actions, упаковывает ZIP и считает SHA-256. Ветка `main` обновляет предварительный релиз `continuous`; теги `v*` публикуют стабильные релизы. Ошибки сборки должны быть видны в логах соответствующего запуска Actions.

Исходники и YAML: UTF-8 без BOM, окончания строк LF.
