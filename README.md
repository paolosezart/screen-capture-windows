# ScreenShotCli

Консольная утилита для Windows: захватывает прямоугольную область рабочего стола и сохраняет её в PNG.

## Возможности
- Координаты: `--x`, `--y`; размер: `--width`, `--height`.
- Путь сохранения: `--output` или `-o`.
- PNG, автоматическое создание папки назначения.
- Несколько мониторов, в том числе отрицательные координаты.
- Проверка границ и защита от чрезмерного размера области.
- Self-contained EXE для Windows x64; .NET Runtime устанавливать не нужно.

## Где скачать готовую программу

Открой вкладку **Releases** репозитория. Успешные сборки веток `main`, `master` и `dev` публикуются как предварительные релизы (Pre-release). Версии с тегами `v*` публикуются как стабильные релизы.

Каждый релиз содержит:
- `ScreenShotCli-win-x64.zip` — архив с EXE.
- `SHA256SUMS.txt` — SHA-256 для проверки архива.

Actions Artifacts остаются временным хранилищем сборок и диагностических файлов. Основное место скачивания программы — **GitHub Releases**.

## Ветки и процесс разработки

- `main` — стабильная ветка.
- `dev` — рабочая ветка для разработки и предварительной проверки.
- `ci-feedback` — отчёт о последней неудачной сборке: [reports/latest.md](https://github.com/paolosezart/screen-capture-windows/blob/ci-feedback/reports/latest.md).

Изменения в `dev` запускают предварительную сборку. Для стабильного релиза создай и отправь тег, например `v1.0.0`.

## Диагностика и исправления

При ошибке сборки workflow:
1. Сохраняет полные логи как Actions Artifact на 7 дней.
2. Создаёт или обновляет очищенный от типовых токенов фрагмент диагностики в `ci-feedback/reports/latest.md`.
3. Не запускает сам себя повторно: ветка `ci-feedback` не включена в триггеры сборки.

Расширенный режим работы над одной задачей — до 10 последовательных циклов анализа отчёта, исправления исходников и новой сборки. Исправления исходного кода выполняются в ходе работы над проектом; CI не изменяет исходники самостоятельно.

**Ограничение:** workflow не является автономным AI-агентом и не исправляет код сам по себе. Для автоматического продолжения после завершения чата потребуется отдельный агент/сервис с соответствующими полномочиями.

## Использование

```bat
ScreenShotCli.exe --x 0 --y 0 --width 800 --height 600 --output "C:\Screenshots\part.png"
ScreenShotCli.exe --x 100 --y 200 --width 1280 --height 720 -o "D:\Capture\screen.png"
ScreenShotCli.exe --help
```

Код возврата: 0 — успех, 1 — ошибка захвата/сохранения, 2 — ошибка параметров.

## Примечания
- Координаты отсчитываются от левого верхнего угла виртуального рабочего стола.
- Вся область должна находиться внутри рабочего стола. Максимальная сторона — 16384 пикселя; площадь — 100 миллионов пикселей.
- Существующий файл перезаписывается.
- Захватывается интерактивный рабочий стол текущего пользователя; курсор отдельно не рисуется. Защищённые экраны и DRM-видео могут не захватываться.
- Не запускай от администратора без необходимости.
- Текущая целевая платформа: .NET 8 / Windows x64. Исходники и YAML: UTF-8 без BOM, окончания строк LF.
